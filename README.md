# Volt — متجر إلكترونيات تجريبي (Volt): مقارنة المواصفات، تصفية حسب العلامة والفئة، بحث، سلة محفوظة في localStorage، وإتمام شراء تجريبي.

متجر تجريبي ثنائي اللغة (العربية RTL والإنجليزية LTR) مبني بـ React وTypeScript وVite وTailwind CSS.

## التشغيل

```bash
npm install
npm run dev
npm run build
```

## المزايا

- متجر إلكترونيات تجريبي (Volt): مقارنة المواصفات، تصفية حسب العلامة والفئة، بحث، سلة محفوظة في localStorage، وإتمام شراء تجريبي.
- تبديل اللغة من الأعلى، ويُحفظ الاختيار في localStorage
- بحث وتصفية وترتيب، وسلة محفوظة في localStorage، وقائمة مفضلة
- إتمام شراء تجريبي بدون دفع حقيقي
- ترجمات في `locales/en/common.json` و`locales/ar/common.json`

## ملاحظة

واجهة تجريبية. الأسعار والمنتجات عينات، ولا تُنفذ طلبات حقيقية.
